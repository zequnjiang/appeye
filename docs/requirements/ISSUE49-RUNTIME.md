## 已知事实与边界

发布`bd5c171`后，Alex正式浏览器首页出现30秒超时；第二轮新版资源、登录及一项APR展示通过后，身份诊断等待10秒仍为loading。CEO另以本机HTTP请求复现5秒超时，暂停独立大库审计后仍可出现。原探针失败保留，页面JS错误为空不等于流程成功。

原生运行栈提示同步SQLite读取期间事件循环受阻，但**尚不能据此认定具体SQL或索引为根因**。CEO在只读备份上的初步单项计时：候选查询约336ms、来源8ms、批次任务15ms、快照版本10ms；这些单项本身不足解释超过30秒阻塞。后续应直接追踪完整实际请求/collector路径，区分启动就绪、同步执行、外部网络、缓存及审计IO影响。

本次仅修复已证明的阻塞路径。不改变商店分页、来源预算、限速、公平调度、分类、评论计数或原批次2024成员；不借删队列、重置cursor、停止collector或永久关闭某通道换取页面响应。既有失败和更早证据保持。#11来源审计/timeline通过不等于#49已修复，#49通过也不代替#11运营终验。
