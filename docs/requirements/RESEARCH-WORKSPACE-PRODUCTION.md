## 目标、现状和交付范围

把用户已验收的“每日六国变化 → 应用研究 → 保存客户研究”完整流程接入正式系统。页面沿用原型的信息架构和交互，市场信息来自已有真实数据库，研究操作持久保存，由服务端执行身份/角色/空间授权。不能只换外观、继续使用 fixture 或把原型有结果的动作改为占位提示。

已确认的技术现状：`server/app.ts` 使用共享管理员密码与内存会话，所有受保护旧 API 目前只检查登录；`server/db.ts::listApps` 固定首次发现倒序及 offset 分页，没有真实查询快照。已有应用、快照、变化、评论、完整补充、分类证据、小时监测和六小时扩展发现可复用；尚无用户/成员/客户研究模型。`NormalizedApp` 已提供 `icon/screenshots/developerWebsite/privacyPolicy`，不需用原型示例 URL 或图标填补正式资料。

完整页面范围包括：今日市场、国家市场、应用库、最多四项对比、应用详情、我的关注、研究空间、收录申请、客户成员管理，以及平台候选核对、识别规则、漏收诊断、采集运行、国家配置、客户/成员管理。真实持久操作取代演示按钮。独立 4173 原型保留参考用途，正式入口不显示演示身份切换、模拟检测、重置示例或示例数据。

继续使用 Node.js 24+、TypeScript、Express、React/Vite、SQLite SQL+JSON 和指定采集库。此次不做 AI 分析、支付、自助注册、公司关系图、真实邮件/短信发送或另外一套采集系统。邀请由管理员生成链接并复制分享；不以缺邮件服务为由省略邀请流程。

## 身份、角色与空间

账户、成员关系、邀请和客户会话须持久化；密码使用带盐的密码专用哈希，不能明文或普通 SHA256 保存密码。会话 Cookie 沿用 HttpOnly/同源约束，部署 TLS 时使用 Secure。客户登录不能再使用全局管理员密码，不能由浏览器提交的 role/workspaceId 决定权限。

可保留现有 `ADMIN_PASSWORD` 作为过渡的 **platform operator** 入口，但它只建立平台身份，不扮演客户，不成为绕过私有研究授权的后门。平台创建客户空间并邀请首位管理员，真实研究必须发生在一个有成员授权的客户空间。账户可有多个合法空间成员关系，切换只允许自身有效成员空间；不存在原型任意七身份切换能力。

| 能力 | 平台运营 | 客户管理员 | 研究员 | 只读成员 |
| --- | --- | --- | --- | --- |
| 浏览公共已确认市场、详情、排序、对比 | 可 | 可 | 可 | 可 |
| 浏览本空间关注/研究、导出已有研究 | 不默认拥有客户空间权限 | 本空间可 | 本空间可 | 本空间可 |
| 写关注/分组/集合/备注/摘录/个人已读 | 不以平台身份代写 | 本空间可 | 本空间可 | 不可 |
| 管理成员、生成邀请、改角色/移除 | 可管理客户及成员元数据 | 仅本空间 | 不可 | 不可 |
| 收录申请 | 核对/处理 | 本空间提交/查看 | 本空间提交/查看 | 本空间查看 |
| 候选、分类细分、规则、诊断、采集、国家 | 可执行真实操作 | 不可 | 不可 | 不可 |

平台管理客户/成员元数据不授权读取客户备注、摘录、集合内容或导出。跨空间访问通过 URL/对象 ID、请求体、批量接口、详情关联、搜索、导出或旧 API 均被拒绝。被移除、停用或降权的成员，旧会话下一次请求立即按新权限处理；跨身份/空间切换清除客户缓存、待更新快照和选择上下文。只读成员浏览不能顺带写已读状态。

邀请绑定目标规范化邮箱、空间、允许的客户角色、创建者和过期时间。随机单次令牌只存哈希，默认 7 天有效，可撤销/重新生成，旧令牌不能继续授权；原文只在生成/复制时提供，不进入普通审计日志或客户端持久缓存。接受邀请须事务性消费，并发两次仅一次成功。新账户设置自身密码；已有账户须以对应账户认证接受，不能借邀请覆盖已有账户密码或更换邀请邮箱。管理员只能邀请本空间客户角色，不得授予平台角色。创建待邀请的空空间允许；移除/降级最后一个有效客户管理员须拒绝，或由平台在同一有效操作中明确安排替代管理员，不能留下无人可管理的活跃空间。链接持有与管理员分享流程不冒称经过外部邮箱验证。

## 真实市场和现金贷口径

客户公共市场可见性统一为持久化的有效 `classification=confirmed`，兼容现有 auto/manual/legacy 来源，人工/历史覆盖继续优先。未经确认和 excluded 仅供平台运营；猜到应用 ID、快照 ID、评论/补充地址、原始数据或 CSV 端点不能绕过同一可见性。客户不能通过传 `classification=candidate` 解除限制。

现有 `loanAnalysis.productType='personal-loan-or-facilitator'` 是宽泛贷款线索的回退，不足以证明“个人现金贷”。增加独立细分类，本轮明确为 `personal/other/unknown`，personal 表示人工核对的个人现金贷，other 表示其他已确认信贷；已有无可靠细分证据的数据迁移为 `unknown`，不从标题、Finance 类别、confirmed 或 hasLoan 自动推成现金贷。现有 productType 原文仍展示为规则线索，不因为三档研究范围而丢失原有更详细信息。

**客户默认范围为“个人现金贷及待细分”**：有效 confirmed 且细分类为 personal 或 unknown；unknown 明确显示“待细分”，并提供严格“仅个人现金贷”、“其他已确认信贷”、“待细分”和“全部已确认信贷”筛选。默认排序仍为累计安装下限倒序，不加入与用户选择冲突的隐藏分类排序权重。平台可人工细分并记录旧值/新值、操作者、时间、原因和可用来源引用；不改写已有信贷分类或伪造商店更新事件。首页、国家事件、应用库、对比、关注筛选和导出使用一致范围，页面显示实际过滤口径及待细分数量。

今日市场复用 `market-activity.ts`，默认真实北京时间当天、支持历史日期和空日期；不使用原型固定 132/120/12 或 30/23/64 数字。六国对照由同一实际查询派生，后续国家配置可扩展。分类/国家/商店/细分类过滤影响计数及事件；各类型的唯一市场应用数与事件条数分别表达，同应用跨国独立计数。

系统首次发现、商店发布日期和实际观测更新时间继续分开。商店只给日历日期时保留精度，不能编造时刻或声称该国首次可用；首次成功快照不制造更新。更新详情按真实 snapshot/change 关联提供 before/after、版本、releaseNotes、来源和 observedAt；公司/条款变更与实际可用字段一致。首页“最近动态”取相同筛选范围的真实最新事件，不使用固定“几小时前”。精选区使用有说明的确定性最新/关注事件规则，最多四条，实际不足则按实际数量展示，不补假事件或称 AI 推荐。

## 应用库、详情与阅读稳定

应用库支持名称/开发者/外部 ID 搜索、国家/商店/细分类、商店发布日期范围、评分及安装下限过滤。九字段 `title/developer/firstSeenAt/releasedAt/storeUpdatedAt/lastFetchedAt/score/ratings/minInstalls` 均可升降序；全集筛选后排序再分页，数字按数字、日期按规范化时间键，0 有效、未知末位、同值稳定 ID 兜底。仅日期精度可作为日期排序键，不对用户补造发布时刻。默认 `minInstalls desc`；GP 公开累计安装下限不当国别下载，Apple 缺失不当 0。图标使用该应用已采集字段，缺图/错误有占位；日期列保持商店发布 → 商店最近更新，首次发现仍在详情/可选排序。

**正式服务端查询快照必须兑现稳定分页。** 返回不可猜测 token、筛选/排序、asOf、expiresAt、total 和有序结果；冻结满足查询的有序身份与用于显示的字段版本/紧凑行值，而非每页重新查询实时 apps。token 绑定用户、会话、空间和完整查询/权限范围；不可跨账号、空间或参数复用。快照必须能跨页面往返及服务重启继续使用；本轮有效 12 小时、每会话最多 20 个并定期清理，被淘汰/过期均明确返回失效状态。过期明确提示，由用户刷新获取新快照，不静默重排当前清单。成员/公开可见权限变更时服务端重新授权，必要时强制使整份快照失效；稳定阅读不能成为泄露已撤销权限资料的例外。

浏览器每 15 秒检测是否有可应用的新数据，保持 displayed 行/total/分页直到用户点击更新；隐藏页暂停、恢复补一次、同查询单次请求，失败保留旧显示并轻提示。更新/换筛选原子回有效页，取消或忽略过期响应。详情、国家事件、关注组、集合返回分别恢复入口、筛选、排序、页码和阅读锚点；顶部不因新行被拉离控件区。切角色/空间不复用前一 scope 缓存。单看客户端缓存而后台 offset 不稳定不算完成。

对比 2–4 个当前可见应用，跨页选择、移除可用，第五项拒绝；展示真实条款/主体/指标/权限状态和来源，不把不同币种/利率周期直接排名。每个 ID 的服务端读取权限独立检查。

详情必须接通已采集的介绍、贷款证据/条款、公司与发布者分角色信息、版本/字段变化、指标趋势、评论样本、截图、权限/隐私及全部原始字段分页入口。指标只画实际观测点，更新频率沿用已观测有效版本，不编造完整历史。截图使用真实 screenshots，缩略/灯箱/前后/键盘/关闭焦点及缺图/失败分支可用。权限默认紧凑六项、展开完整原条目与未知字段；未采集、成功空、最新失败留旧、unsupported 分开，Apple 不编 Android 权限，SDK type 不当风险等级。

标题下 ID/商店按当前 country/store/externalId 打开官方目标；基本信息官网与隐私分别来自真实 `developerWebsite/privacyPolicy`（DTO 可映射为 websiteUrl/privacyUrl），无数据明确缺失，不能填 example.com 或猜主体网站。安全 HTTP(S) 新标签配 noopener/noreferrer，原详情保留。发布账号/卖方/描述中的运营或贷款主体保留各自来源，不合并成已核验法人。公司编号、披露规则与信贷确认均不等于牌照合法性。原始 HTML/JSON 和用户研究内容安全显示，不执行注入脚本。

## 真实研究与收录操作

关注关系、分组及成员、集合及成员、备注、来源摘录在所属客户空间共享并落库；个人已读以 user + workspace + 稳定 event ID 保存。新事件不能因同应用旧事件已读而自动消失。分组/集合创建、改名、加入/移除、删除，关注/取消、备注新增/编辑/删除，均有真实持久结果及空态；未保存、冲突或失败不能给假成功提示。研究正文/摘录条目的编辑和删除都用 revision/等效冲突控制；旧列表不能删除另一成员刚保存的新版，冲突返回 409 并保留正文。分组/集合的短标签和成员结构采用有授权的显式最后操作语义，本轮不追加全面协同版本协议；删除分组/集合不删除研究正文。

摘录保存当时正文与来源锚点：app/国家/商店/外部 ID、event/change/snapshot 或补充 history ID、源字段/可用 offset、来源 URL、原观测时间、创建者和创建时间。服务端验证引用对象属于同一可见应用、摘录确实对应该来源，不能信任客户端伪造的 eventId 或“引用原文”；后续市场更新不改写旧摘录。普通研究备注与原文摘录分清，不把用户观点呈现为商店事实。

共享应用后来退出客户可见范围，既有私有备注/摘录仍归原空间保存，显示来源已不在当前公共库及已保存的历史引用；不能借旧引用取出其他当前受限详情/原始资料。删除成员不删除整个空间的共享研究，个人读状态不泄漏给另一用户。

交付真实 Markdown 导出，支持当前空间和单一集合，包含导出范围/时间、身份、备注/摘录及来源/原时间；服务端根据授权范围生成完整响应与下载文件名，不能只导出前一页或让浏览器传 workspaceId 就读他人数据。原型预览/复制可保留作补充，但不能代替正式导出接口。保留现有平台应用 CSV 能力，并按实施期间已授权的实用补充提供客户应用库 CSV：由当前会话/完整查询绑定的有效服务端快照导出全部冻结行，保留显示顺序、身份、来源、日期精度、细分类及快照时间，不在导出时悄悄创建实时新查询。过期/已撤销公开权限的快照同样拒绝。CSV 处理公式注入并保留 null/0 区分，明确 GP 公开累计指标与 Apple 未公开边界。文件下载尝试不提前宣称已保存到用户磁盘。

客户未找到包名可提交 country/store/externalId 收录申请，记录请求人、空间、时间、备注和状态；空间内可查，另一客户看不到申请内容。相同身份可复用全局采集任务，但各空间申请及处理记录独立。平台查看申请、核对诊断、批准排队、拒绝并给理由、失败后有限重试，须真实关联原任务/响应/分析。

建议状态为 submitted/reviewing/collecting/pending_confirmation/admitted/rejected/failed，或等效清晰模型。**排入任务或创建 candidate 占位不等于成功收录**；只有该身份已有真实成功详情且当前 confirmed 才能标为客户可用 admitted。strong 可沿既有自动规则确认，人工 excluded 不自动覆盖；需人工决定时由平台单独记录。成功后客户能进入正确市场身份详情；来源不可用时保留真实错误和重试历史，不回退 demo。重复批准/重试幂等，不创建重复 app 或无限任务。

## 平台运营与兼容性

候选核对复用既有分类/人工覆盖和来源，补充细分类人工核对。正式规则页的在线编辑明确限定为 `autoConfirmStrong`：控制后续强信贷证据是否自动确认，保存递增配置版本、操作者与时间；页面显示受控开关、当前版本及原识别/披露规则，不能只改 UI 名称或把无效开关宣称生效。新增显式“重新分析当前资料”执行入口，使用现有真实资料和原观测时间，不新抓数据、不伪造商店更新；保留 manual/legacy 决定，分析结果可更新但不能改人工有效分类。原政策词表/正则/官方事实仅作只读展示，变更继续通过版本化代码与 GitHub 审核，不开放任意在线政策编辑器。每次分析保留官方规则版本与生效配置版本，不用配置版本覆盖来源版本；开关修改本身不暗中无界重算旧资料。

漏收诊断展示已有公开有界发现/暂存/排队/失败/入库证据和停止原因；平台可用已知 ID 发起实际受限任务。运行页显示小时、扩展和原批次的真实进度/失败/游标，重试按钮接真实有限重试。国家/语言/关键词/启停修改真实配置并由现有调度使用；每小时详情和六小时扩展节奏不因 UI 改造改变。新增国家沿已有扩展机制，不静默复制另一国政策结论。平台客户/成员操作有实际账户/空间/邀请状态，不再“模拟接受”。

数据库采取增量迁移，保留 apps、全部快照/评论/补充/来源/原始 HTTP、分类/人工覆盖、国家配置和队列历史。研究/会话/审计采用明确关系表和外键，源大 JSON 通过稳定引用追溯；不把每次列表快照复制成全量原始 HTTP。角色、邀请、成员、分类、规则和收录处理记录可追溯操作人，普通日志/客户接口不泄露密码、token、会话或其他空间内容。

继续现有采集协调器、OS 锁与有限任务预算，不另开普通 worker 抢单；研究写事务短小、并发读写有可控 busy/错误处理。#11 原批次以既有 2024 cohort 验收，合法小时新观测与新应用不扩张原批次分母，本次不能宣称原扫描完成。上线前 CEO 做真实备份、停止点/迁移保留核对与恢复；数据库体积与后台负载必须用真实或隔离证据分别记录，不以玩具库证明线上速度。
