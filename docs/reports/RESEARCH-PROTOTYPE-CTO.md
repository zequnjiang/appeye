## 交接与边界

应用状态只在本次页面会话保留，刷新原型页面恢复示例；页面内详情往返不刷新文档。七个固定身份用于体验角色，成员记录编辑不等于真实账户授权。后台每 15 秒模拟检测默认由演示账号菜单显式开启，也可点击顶部执行一次检测；其后必须点击应用 pending 才改变清单。同一示例只产生一条新身份，已应用后可重置再演示。

无真实采集、登录、邮件、金融验证或客户安全隔离完成声明。浏览器截图、窄屏布局、焦点/滚动与全部用户操作结果待 CEO/Alex 独立报告；这些验证通过后由 PM 最终验收。

## 图片失败演示与下载触发增量（2026-09-09）

按 CEO/Alex 的实际浏览器验证需要，TH9 增加明确故意的本地 404 截图路径。其描述、`screenshotStatus` 与 `screenshotNote` 均说明这是原型失败分支，不能解读为商店图片或采集失败。TH1 保留正常两图，其他应用仍无图。灯箱和缩略图替代文本随当前应用身份显示。

CEO 报告 IAB 原下载未收到下载事件，因此改为独立 `requestDownload`：把链接附加到页面后触发点击、移除链接，并延迟 60 秒撤销对象 URL。反馈改为“已发起示例文件下载”，不再提前承诺文件已保存。CTO 可控 DOM 测试验证实际调用顺序、文件名和延迟；真实下载是否完成由 CEO 浏览器复测确认，必要时再实现可见内容降级。

此增量后 `npm test` **22/22 通过**（Alex 12、CTO 6、runtime 4），`npm run build` 通过，JS 已重新冻结。

## IAB 实测驱动的最终交互修正

CEO 精确复核了截图按钮按 Enter 打开、关闭按钮按 Escape 后焦点落到 BODY 的问题。Dialog 现在用稳定引用保存入口，关闭原生 modal 后下一帧恢复；StrictMode 再次打开时不把焦点移到 inert 的背景。新增生命周期测试覆盖 setup/cleanup/setup、最终关闭与入口已离开文档的情况。真实入口焦点结果交 CEO 复测，纯测试不能替代浏览器行为。

标准挂载链接下载仍未在 IAB 产生下载事件，故导出改为先展示完整当前空间 / 集合 Markdown 的可见对话框，保留“发起文件下载”，并提供“复制完整内容”和“全选内容”。Clipboard API 被拒绝时不会假称成功：尝试标准复制后按实际结果提示，或选择全文供系统复制。此降级无需服务器，也不改变导出作用域。

上述增量后 `npm test` **23/23 通过**，最终 `npm run build` 通过。一次本地代码替换留下的语法片段在构建时暴露并已移除；最终构建无未处理错误。JS 再次冻结后通知 CEO/Alex 复测。
