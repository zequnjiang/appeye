## 本次预审发现与澄清

1. **RWP-PM-01：陈旧条目删除。** 条目 PATCH 有 revision，但初审 DELETE 仅按 ID 删除，旧清单可删除另一成员刚保存的新版。CEO 已接并补服务端版本条件，CTO/Alex 正在接入及独立回归；未收到闭环前不记为通过。限定研究正文/摘录条目，分组/集合短标签保留显式最后操作语义，删除容器保留研究正文。
2. **RWP-PM-02：详情日期显示。** 复用 `LegacyApp` 的日期助手按浏览器本地时区解析 date-only，负时区可能显示前一天，和正式市场页的日期精度/北京时间不同。已交 CTO/Alex 做最小同源显示修正；不修改真实来源数据。
3. **RWP-PM-03：详情中已选事件引用。** 初审 `ProductionDetail` 即使当前详情返回 404，仍可无条件显示 route 中旧 `SelectedEvent` 与新研究动作；已交 CTO/Alex 核对并在明确授权拒绝时清除本地引用。已保存的本空间历史摘录继续保留，普通网络错误不能误当权限撤销。
4. 按 CEO 已授权补充，需求 v1.1 明确客户 CSV 导出当前快照的冻结全集及顺序，保留原有平台 CSV；不是扩大为另一份实时查询。
