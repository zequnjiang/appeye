## 差异与恢复的处置

首次独立 XML 审计保留了 task 29909 / HTTP 20073 的 1 处差异及不可变初次产物：Python XML 标准将字面 CRLF 转为 LF，而 SDK/库保留 CRLF，分别为 194 / 195 个 Unicode 码点。CTO 注入同一保存 HTTP、用实际 SDK 离线重放，全部 50 条 raw 完全相同；PM 另核原 HTTP SHA-256、50 行 raw 哈希及原 entry 含完整保存字符串。最终审计只接受有源字节支持、仅 CRLF 归一化后严格相同的文本，不泛化 trim 或忽略字段。**接受为 1 处已解释的解析投影差异；没有生产丢字段证据，也不修改原文。**

3,804 条 HTTP 比成功页多出的 1 条来自受控切换时的中断：墨西哥 app 239、第 2 页 task 23042，原 HTTP 13202 / attempt 23178 于 `20:13:15.375Z` 留存；attempt 23179 于 `20:13:46.800Z` 恢复并成功，合法空响应观测时间为 `20:13:47.480Z`。PM 再核两个 attempt 和原失败 HTTP 都在；它不是未解决的 Apple 评论失败，不能与后来 Google 的网络失败混写。
