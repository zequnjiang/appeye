## 实现

008 增量迁移增加客户空间、用户/成员、一次性邀请、服务器会话、查询快照、共享关注/集合/备注/摘录、个人已读、收录申请、细分类与规则配置、审计。源市场表、原始 HTTP 及已有采集调度继续沿用。客户密码与过渡平台认证均使用带盐 scrypt；随机会话及邀请只存哈希，配置 SESSION_SECRET 后使用 HMAC 绑定会话并支持轮换撤销。

每次请求检查账户/空间/成员当前授权。平台仅管理客户元数据，不隐含客户研究读取权限；客户对旧 API 的访问也必须通过平台或已确认应用的同一授权分支。真实邮箱/密码登录、受邀新账户、已有账户验证原密码、多空间切换、降权/停用撤销会话和最后管理员保护均落库。

公共库以 confirmed 为边界，默认个人现金贷及待细分；原 loanAnalysis 回退类型不当个人现金贷证据。九字段全量过滤/排序后冻结紧凑行值，快照绑定会话及完整查询，12 小时、每会话最多 20 份，跨重启有效。probe 不自动替换行，CSV 必须使用当前快照导出其全部行，null 与 0 分开并防公式注入。自然失效明确报 410；公开范围撤销另带 SNAPSHOT_SCOPE_REVOKED，已清空记录保留有界标记，以便后续并发 probe/CSV 不误判为普通过期。

研究来源在服务器验证所属应用、源记录与原文匹配；引用正文/来源身份/原观测时间冻结保存，编辑使用 revision 防覆盖。共享研究与个人已读分别建模，历史私有研究不因公共应用退出而丢失，也不能借此访问受限原始资料。Markdown 按授权空间/集合完整生成。

收录申请复用真实任务，只有关联任务实际成功、成功详情时间满足并且当前 confirmed 才标 admitted；创建 candidate 或排队不是收录成功。规则在线编辑限定 autoConfirmStrong，版本递增，显式重分析用已有资料和原观测时间，保留 manual/legacy。
